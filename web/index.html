Todavía no tenés sub-bots

Creá el primero: elegís prefijo y etiqueta, tu número y vinculás con pairing code o QR.

⚠️ Alcanzaste el máximo de 3 sub-bots. Eliminá uno para crear otro.

🚀 Desplegar este panel

Publicá el panel en la nube con el Blueprint de Render o con Vercel, directo desde el repo.

R

Blueprint en Render

render.yaml incluido

Render lee el render.yaml del repo y crea el servicio web tomioka-panel solo: corre node scripts/serve-web.js y usa el PORT que Render asigna.

  1. Tocá el botón (o en Render: New + → Blueprint)
  2. Elegí el repo TomiOka y aplicá el Blueprint
  3. Listo: tu panel queda en *.onrender.com
Deploy to Render ↗
▲

Desplegar en Vercel

vercel.json incluido

Vercel lee el vercel.json del repo y publica la carpeta web/ como sitio estático, sin paso de build. Cada push redespliega solo.

  1. Tocá el botón (o en Vercel: Add New → Project)
  2. Importá el repo TomiOka y confirmá
  3. Listo: tu panel queda en *.vercel.app
Deploy with Vercel ↗

Ambos despliegues publican solo el panel web. El bot de WhatsApp (Baileys) necesita sesión persistente y un proceso siempre activo, así que sigue corriendo en tu Termux/VPS.
