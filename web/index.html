Open source · Node.js + Baileys

Bots de WhatsApp con una arquitectura clara y herramientas reales.

TomiOka es una plataforma abierta para construir bots modulares en Node.js. Incluye motor de stickers, packs, comandos extensibles, diagnóstico del entorno y una base pensada para Termux, Linux y VPS.

Del primer arranque a tu propio comando

Ejemplos basados en la estructura real del proyecto. Puedes copiar cada bloque y adaptarlo a tu entorno.

Instalación en Termux

Instala el runtime, FFmpeg y las dependencias del proyecto.

Terminal
pkg update -y
pkg install -y nodejs-lts git ffmpeg libwebp

git clone https://github.com/lyanvalentinmail-prog/TomiOka.git
cd TomiOka
npm install
npm run doctor

En Linux o VPS puedes instalar Node.js y FFmpeg con el gestor de paquetes de tu distribución y ejecutar los mismos comandos de npm.

Configuración esencial

El comportamiento principal se controla desde config.json. El panel superior genera la base de estos valores.

config.json
{
  "bot": {
    "name": "TomiOka",
    "prefix": "."
  },
  "stickers": {
    "packName": "TomiOka",
    "packAuthor": "TomiOka Team",
    "quality": 82,
    "fps": 15
  },
  "behavior": {
    "respondInGroups": true,
    "cooldownMs": 2500
  }
}

Crear un comando modular

Cada comando vive en su propio archivo dentro de src/commands/ y se registra en el índice de comandos.

src/commands/saludo.js
export default {
  name: 'saludo',
  aliases: ['hola'],
  category: 'extras',
  description: 'Saluda al grupo.',
  usage: '.saludo',
  examples: ['.saludo'],

  async run(ctx) {
    await ctx.reply('👋 ¡Hola! Soy TomiOka.')
    return 'saludo enviado'
  }
}

Después importa el módulo y agrégalo a commandList en src/commands/index.js. Ejecuta npm test antes de publicar.

Vincular y ejecutar

Elige código de vinculación o QR. Una vez guardada la sesión, los siguientes arranques se conectan sin pedir credenciales nuevamente.

Arranque
# Vincular con pairing code
npm run pair

# Vincular escaneando un QR
npm run qr

# Arranque normal con sesión guardada
npm start

# Servir esta página localmente
npm run web

No compartas la carpeta sessions/: contiene las credenciales de la cuenta vinculada.
